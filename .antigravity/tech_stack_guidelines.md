- Language: Luau (Roblox Lua)

## Guidelines
- **Workflow:** Always commit and push modifications to GitHub, and copy the updated script to `C:\Users\luigi\AppData\Local\Potassium\autoexec`.
- **Manual Travel & Flight Cancellation:** For manual travel features (e.g., `T_ManualMegStackLoc`), use a dedicated state flag (`Model.State.isManualTraveling`) rather than reusing other flags like `isRefillingMegBait`. When toggled OFF, set `isManualTraveling = false`, `isCraftFlying = false`, and call `Model.DisableFlight()` to immediately pause travel in place rather than triggering an auto-return flight.
- **UI Toggle Initialization & Lobby Safeguards:** In Fluent UI, toggle callbacks execute immediately upon creation with their Default value (`false`). When loading external gameplay scripts (e.g., `protov4_nofactory.lua`), always verify `if Value` before fetching or executing. In addition, always guard gameplay-dependent toggles with `if isLobby then return end` so that synchronous `WaitForChild` calls in external scripts do not freeze UI initialization when loaded in the Lobby.
- **Lua Operator Precedence & Short-Circuit Evaluation:** In Lua, `and` has higher precedence than `or`. Expressions like `if x and x:IsA("A") or x:IsA("B")` will evaluate `x:IsA("B")` when `x` is `nil`, resulting in a fatal runtime error (`attempt to index nil with 'IsA'`). Always wrap compound boolean expressions in parentheses: `if x and (x:IsA("A") or x:IsA("B"))`. In addition, always check `if not isLobby and ...` before executing functions that inspect gameplay elements (like `GetCurrentPSCode()`) to avoid unnecessary execution or nil reference errors in the Lobby.
- **Top-Level Return Statements in Chunk Execution:** Never use `return` at the top level of a main script chunk (such as inside `if isLobby then ... return end` when skipping auto-teleporting in the Lobby). Calling `return` outside of a function terminates execution of the entire Lua file chunk immediately, preventing subsequent UI tabs, buttons, and event loops from loading. Use conditional branching (e.g., `if shouldTeleport then task.spawn(...) end`) instead.
- **UI Close Buttons & Complete Cleanup:** When implementing close/exit buttons in GUI scripts, parent child buttons (e.g., close "X" buttons) to main draggable elements or containers so they move together during user dragging. In cleanup callbacks, ensure complete teardown by explicitly disconnecting all `RunService` event connections (`Stepped`, `Heartbeat`), terminating background loops via running flags (`isRunning = false`), resetting character physics (`Model.ResetPhysics()`), destroying the GUI, and clearing global duplicate execution guards (e.g., `getgenv().FishmanAutoFarmRunning = false`).
